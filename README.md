# Gaming Pro Till — downloads

Windows installer for the **Gaming Pro** offline till (point of sale for PA small‑games‑of‑chance clubs).

## Download

**[Download the latest installer](https://github.com/Lancetvsign/gaming-pro-till/releases/latest/download/Gaming-Pro-Till-Setup.exe)** — no login needed.

1. Run `Gaming-Pro-Till-Setup.exe`. Windows SmartScreen will warn (the installer isn't code‑signed yet): **More info → Run anyway**.
2. Install and launch.
3. Sign in as a **club manager**, then tap **Register this till**.

The Supabase cloud address is built in — there is no config file to place.

---

This repository holds only the installer downloads. The application source code is private.
